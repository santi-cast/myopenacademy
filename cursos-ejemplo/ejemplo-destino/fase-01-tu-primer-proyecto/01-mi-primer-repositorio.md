## Qué aprenderás

## 1. Teoría

### 1.1. Qué es un repositorio

Un [repositorio](../glosario.md#repositorio) es la carpeta de un proyecto junto con toda su historia.

### 1.2. Commits y ramas

Cada [commit](../glosario.md#commit) es una foto del proyecto; una [rama](../glosario.md#rama), una línea de trabajo.

## 2. Ejemplos de código

### 2.1. Un README
