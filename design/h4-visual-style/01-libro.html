📌 Nota: el «¡Hola, mundo!» (Hello, world!) es, por tradición, el primer programa que se escribe al aprender cualquier lenguaje. Sirve para comprobar que todo funciona: el editor, el compilador y la ejecución.

Son solo tres líneas, pero cada símbolo tiene su función:

PiezaQué esPara qué sirve
mainEl nombre del método principalIndica a Java por dónde empezar. Un método es un bloque de instrucciones con nombre; los verás a fondo en el módulo 02.09 todavía no disponible
voidPalabra reservada: «vacío»Indica que main no devuelve ningún resultado cuando termina
()Los paréntesis del métodoAquí irían los datos que recibe el método. Vacíos: no recibe nada
{ y }Las llavesMarcan dónde empieza y dónde acaba el cuerpo del método
IO.println(...)Una llamada a un método de JavaMuestra en pantalla lo que va entre los paréntesis y salta a la línea siguiente
"¡Hola, mundo!"Un texto (en inglés, string)Las comillas dobles marcan dónde empieza y dónde acaba el texto
;El punto y comaMarca el final de la instrucción, como el punto al final de una frase

1.4. Instrucciones y orden de ejecución

Cada orden que das al ordenador es una instrucción (también llamada sentencia, del inglés statement). Una instrucción típica termina en punto y coma.

Java ejecuta las instrucciones de main en orden, de arriba abajo, una detrás de otra. Nunca se salta ninguna ni cambia el orden por su cuenta.

1.11. Cómo se ejecuta tu programa

Pase lo que pase por fuera, por dentro el recorrido es siempre el mismo. Si el compilador encuentra un error en el primer paso, no se genera nada y no se ejecuta nada: primero hay que corregirlo.
