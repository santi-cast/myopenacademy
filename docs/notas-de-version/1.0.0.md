# MyOpenAcademy 1.0.0 — el pack base

*The base pack of MyOpenAcademy, a free, open-source programming academy that installs its courses like DLC. It ships the platform and its first course, «Fundamentos para programar» 1.0.0. Docs in Spanish.*

La primera versión publicada de la academia: **la plataforma más el curso inicial**, «Fundamentos para programar» 1.0.0 (lo que conviene saber antes de cualquier curso: qué es programar, tu ordenador, la terminal, Git y GitHub, los formatos de datos, internet y cómo aprender).

## Qué trae

- **Cursos como DLC:** la academia arranca vacía y cada curso se instala desde su repositorio, por su etiqueta de versión, con el importador sin conexión, que compara antes de aplicar y conserva el avance de los alumnos.
- **Lecciones completas:** ejercicios con pistas y soluciones, preguntas de repaso, diagramas Mermaid, código resaltado, imágenes y carpetas de código en ZIP; retos por fase, glosario, ruta de aprendizaje, chuleta global y proyecto del curso.
- **Avance de cada alumno**, «Mis cursos» y continuar donde lo dejó.
- **Administración:** registro abierto o cerrado, nombre de la academia, cuentas y cursos instalados.
- **Instalación con Docker Compose**, con toda la configuración en variables de entorno.

El detalle está en `CHANGELOG.md`.

## Instalar

1. Sigue `docs/instalacion.md`: configurar el `.env`, `docker compose up -d --build` y crear el administrador.
2. Instala el curso inicial desde su etiqueta `v1.0.0` (apartado 5 de la guía): `content-import generate … --tag v1.0.0`, comparar, aplicar.

Requisitos: Docker con Compose. Probada en Linux; en Windows y macOS debería funcionar con Docker Desktop, pero no se ha probado en una máquina real (si la pruebas, cuéntanoslo en una *issue*).

## Comprobado antes de publicar

- Pruebas del backend (`./mvnw -B verify`), del frontend (unitarias, lint y compilación) y de navegador (`npm run test:e2e`), en verde.
- El curso inicial, instalado desde su etiqueta `v1.0.0`: sin hallazgos ni avisos, sus 613 ficheros y 221 ZIP idénticos byte a byte, 2.843 enlaces con ancla sin ninguno roto, 81 diagramas dibujados y ningún error en el navegador.
- `gitleaks` sobre todo el historial, sin ningún secreto; `npm audit` y las dependencias de Maven (OSV), sin vulnerabilidades conocidas a 16 de noviembre de 2026.
